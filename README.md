## Overview
This Project is made up of a Logger, Encryption file, and a Driver.
- **Logger** (`logger.py`): writes timestamped log messages to a file.
- **Encryption program** (`encryption.py`): encrypts and decrypts strings with a Vigenère cipher.
- **Driver** (`driver.py`): interacts with the user, launches the other two programs, and communicates with them through pipes.
